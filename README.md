# نظام الموارد البشرية

نظام متكامل لإدارة الموارد البشرية وفق نظام العمل السعودي. واجهته عربية بالكامل، ويعمل على الكمبيوتر والجوال.

## المزايا

| الوحدة | ماذا تقدم |
|---|---|
| **تهيئة النظام** | بيانات الشركة كاملة، الشعار، مواعيد العمل (البداية، النهاية، الاستراحة، فترة السماح، أيام العمل، تاريخ السريان)، دوامات إضافية (رمضان، ورديات)، الأقسام والهيكل التنظيمي، مواقع الحضور |
| **الموظفون** | البيانات الشخصية والوظيفية، الراتب والبدلات، رفع السيرة الذاتية PDF والمستندات، حساب دخول للموظف |
| **الحضور والانصراف** | تسجيل عبر GPS من المواقع المحددة فقط، التقاط صورة الوجه، كشف استخدام جهاز واحد لأكثر من موظف (منع + تنبيه للشركة)، حساب التأخير بالدقيقة بعد فترة السماح والخصم من الأجر، احتساب الغياب |
| **الإجازات** | سير عمل كامل: الموارد البشرية (حساب الاستحقاق 21/30 يوماً وآخر إجازة) ← المدير المباشر ← مدير القسم ← تعيين البديل ← إخلاء الطرف من جميع الأقسام ← توقيع المدير الإداري ← تسوية المستحقات ← اعتماد التسوية ← توقيع الموظف ← التأشيرة ← تحويل المالية مع الإيصال ← الأرشفة |
| **المخالفات** | التحقيق وجمع الأدلة ← إفادة الموظف (أو رفضه بشهادة شاهدين، أو غيابه مع إثبات المراسلات) ← اختيار البند من لائحة تنظيم العمل وحساب التكرار والجزاء تلقائياً ← اعتماد المدير الإداري وتطبيق الخصم |
| **العمل الإضافي** | فقط بطلب من القسم: اعتماد ← تخصيص الموظفين ← تأكيد التنفيذ، ويُحسب الأجر وفق المادة 107 (أجر الساعة + 50% من الأساسي). الخروج المتأخر لا يُحتسب إضافياً |
| **الأداء والوصف الوظيفي** | تقييم بمعايير موزونة واطلاع الموظف، وبطاقة وصف وظيفي لكل مسمى |
| **التقارير والأرشيف** | ملخص مسير الرواتب الشهري (خصومات، إضافي، صافي) وتصديره إلى Excel، وأرشيف إلكتروني لكل المستندات، ونماذج رسمية للطباعة (نسخة ورقية) |

## الصلاحيات

- **مدير النظام**: كل الصلاحيات.
- **الموارد البشرية**: كل المعاملات والملفات.
- **المدير الإداري**: توقيع الإجازات واعتماد التسويات والجزاءات.
- **القسم المالي**: تحويل المستحقات ورفع الإيصالات.
- **موظف**: الحضور وتقديم طلباته. إذا كان الموظف مديراً مباشراً أو مدير قسم تظهر له موافقات فريقه تلقائياً.

## التشغيل

يتطلب Node.js بإصدار **22.13 أو أحدث**، ولا يحتاج قاعدة بيانات خارجية (يستخدم SQLite المدمج).

```bash
npm install
npm run build
npm start          # يعمل على المنفذ 3000
```

افتح المتصفح على `http://localhost:3000`. ستظهر صفحة التهيئة لإدخال بيانات الشركة وإنشاء حساب المدير.

- البيانات والملفات تُحفظ في مجلد `data/`. يمكن تغيير مكانه بالمتغير `HR_DATA_DIR`. **احتفظ بنسخة احتياطية منه دورياً.**
- **مهم:** تحديد الموقع والكاميرا في المتصفح يعملان فقط عبر رابط آمن `https`. عند النشر على سيرفر، ضع النظام خلف شهادة SSL (مثل Nginx + Let's Encrypt).
- عند التجربة على شبكة داخلية بدون https، يمكن تشغيل السيرفر بالمتغير `HR_INSECURE_COOKIE=1`.

## ملاحظة نظامية

جدول المخالفات مبني على اللائحة النموذجية لتنظيم العمل، ويمكن تعديله بالكامل من «تهيئة النظام ← لائحة المخالفات». راجعه مع لائحة منشأتك المعتمدة قبل التطبيق.
